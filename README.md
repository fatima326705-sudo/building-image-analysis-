Building Image Analysis

Project Overview

This project analyzes building images using Python. It uses NumPy for numerical calculations and Matplotlib for visualizing image analysis results.

Objectives

Collect building images from Wikimedia Commons.

Resize images to 200 × 200 pixels.

Analyze image brightness.

Calculate average Red, Green, and Blue (RGB) color values.

Display results using graphs.

Tools and Libraries

Python

Google Colab

Google Drive

NumPy

Matplotlib

PIL (Pillow)

Analysis Performed

The project calculates the average brightness of building images and identifies the brightest and darkest images. It also calculates average Red, Green, and Blue color values to examine the images' overall color characteristics.

Results

The analysis includes brightness statistics, RGB color analysis, and graphs showing the results. The final image count should be confirmed from the completed notebook output.

Conclusion
